# 🎀🌱 To-Do List

> 💗 A cute and simple To-Do List app built with **HTML, CSS & JavaScript**.

A small productivity project with a soft **pink & green aesthetic** 🌸🍃
It was created to practice JavaScript, DOM manipulation, local storage, and interactive UI features.

## ✨ Features

* 🌷 Add new tasks
* 🐸 Mark tasks as completed
* ✏️ Edit tasks
* 🗑️ Delete tasks
* 💾 Save tasks with Local Storage
* 📊 Track completed tasks with a progress bar
* 🎉 Confetti animation when all tasks are completed
* 📱 Responsive design for smaller screens
* 🌸 Cute pink & green glassmorphism UI

## 🛠️ Built With

* 🌐 HTML5
* 🎨 CSS3
* 💛 JavaScript
* 💾 Local Storage
* 🎊 tsParticles Confetti
* ✨ Font Awesome

## 💭 What I Practiced

This project helped me practice:

* 🌱 DOM manipulation
* 🎀 JavaScript events
* 💾 Local Storage
* 🔄 Updating the UI dynamically
* 🧩 Working with arrays and objects
* 📊 Creating a progress indicator
* 📱 Responsive CSS
